# Анализатор журналов событий (CLI)

## 1. Бизнес-требования
Службе поддержки необходимо быстро находить частые ошибки и их источники в больших журналах событий (логах) различных компонентов. Программа должна читать файл построчно (не загружая его целиком в память) и выдавать статистику, а также уметь фильтровать данные по времени, уровню и источнику.

## 2. Реализованный функционал
* **Потоковое чтение**: Файл читается построчно, что позволяет обрабатывать логи любого размера без переполнения памяти.
* **Валидация строк**: Корректные строки парсятся, некорректные (битый timestamp, неверный уровень, пустые поля) пропускаются с сохранением их номеров.
* **Фильтрация**: 
  * По времени (`--from` включительно, `--to` исключительно).
  * По уровню (`--level`).
  * По источнику (`--source`).
* **Агрегация**: Считает общее количество строк, количество валидных/невалидных строк, количество событий после фильтрации, распределение по уровням и источникам, а также Top-N кодов ошибок (ERROR).
* **Форматы вывода**: `text` (в консоль), `json`, `csv`.

## 3. Синтаксис и примеры (CLI)
Программа запускается через модуль `loganalyzer.cli`.

**Параметры:**
* `--input` / `-i`: Путь к файлу лога (обязательный).
* `--from`: Время начала (включительно) в формате ISO 8601 UTC (например, `2026-09-01T00:00:00Z`).
* `--to`: Время окончания (исключительно).
* `--level`: Уровень лога (TRACE, DEBUG, INFO, WARN, ERROR).
* `--source`: Имя источника (например, `auth-api`).
* `--top`: Количество топовых ошибок для вывода (по умолчанию 5).
* `--format`: Формат вывода `text`, `json` или `csv` (по умолчанию `text`).
* `--output` / `-o`: Путь к выходному файлу (обязателен для `json` и `csv`).

**Пример 1. Полная сводка в терминал:**
```bash
python3 -m loganalyzer.cli --input logs_events_sample.log
python3 -m loganalyzer.cli \
  --input logs_events_sample.log \
  --from 2026-09-01T00:00:00Z --to 2026-09-02T00:00:00Z \
  --level ERROR --source gateway --top 3 \
  --format json --output report.json
python3 -m loganalyzer.cli \
  --input logs_events_sample.log \
  --from 2026-09-03T00:00:00Z --to 2026-09-05T00:00:00Z \
  --source auth-api \
  --format csv --output auth.csv
